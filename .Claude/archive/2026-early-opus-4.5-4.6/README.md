# Archive: early 2026 (Opus 4.5 / 4.6 era)

Notes written while building Qivis with earlier Claude models, Feb to Mar 2026.
Archived on 2026-09-27 when work resumed with Opus 5.5. Kept as they were, and
labeled as belonging to that time and those collaborators.

- `scratchpad.md`: a prior model's scratchpad (brainstorming, reflections,
  poems, notes on Kashmir Shaivism and the intervention pipeline).
- `qivis-dev-workflow.md`: the strict test-first loop (contract tests,
  integration tests, implement, cleanup, regression) that governed Phases 0-9.1.
  Replaced by lighter norms: verify against the real system, keep tests as a
  safety net, and never silently change a test to make it pass.
